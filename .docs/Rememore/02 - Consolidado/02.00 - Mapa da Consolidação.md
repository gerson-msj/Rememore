# 02.00 \- Mapa da Consolidação

### OBJETIVO

A Consolidação reúne as ideias registradas em Descoberta, onde podem surgir dispersas ou repetidas. Seu objetivo é organizar o entendimento vigente do sistema sem duplicar definições: cada definição fica no documento consolidado responsável pelo assunto.

### CICLO DE CONSOLIDAÇÃO

Quando novos documentos de Descoberta estiverem prontos para serem incorporados, realiza-se uma nova sessão de consolidação. Nela, revisam-se as descobertas pertinentes e os documentos consolidados existentes; estes são atualizados quando necessário, e novos documentos são criados para assuntos ainda sem um documento responsável.

Decisões e ratificações ficam nos documentos responsáveis pelo assunto, não neste mapa.
