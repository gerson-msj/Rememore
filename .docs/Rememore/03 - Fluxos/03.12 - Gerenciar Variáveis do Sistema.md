# 03.12 \- Gerenciar Variáveis do Sistema

## FLUXO

```text
[Área administrativa]
        |
        +-- variáveis do sistema
               |
               -->
[Tela: Variáveis do Sistema | rota: /admin/variaveis]
 dados por variável: nome, descrição, orientação de valores aceitos, valor atual
 valor: texto não vazio
        |
        +-- alterar valor
        |      |
        |      +-- sem alteração --> salvar indisponível
        |      |
        |      +-- valor vazio --> salvar indisponível
        |      |
        |      +-- valor alterado e não vazio --> salvar
        |             |
        |             +-- sucesso --> novo valor vigente imediatamente
        |             |
        |             +-- falha --> informar falha e permanecer
        |
        +-- voltar --> [Área administrativa]
```

## DETALHES

### Objetivo

Permitir ao administrador alterar os valores das variáveis de sistema previamente definidas pelo Rememore, sem transformar a administração em um editor do catálogo de variáveis.

### Referências

02.06 \- Conta, Dados e Administração / Administração do serviço; Variáveis do Sistema; Limites de privacidade do administrador.  
04.02 \- Mapa do Site / Área administrativa.

### Estrutura do fluxo

Variáveis do Sistema é uma jornada administrativa simples. O catálogo é definido pelo próprio sistema e persistido fora da responsabilidade desta tela. A interface não cria variáveis, não remove variáveis e não altera sua identidade ou significado; modifica somente o valor vigente.

### Listagem e edição

Rota funcional: /admin/variaveis.  
Cada variável apresenta nome, descrição, orientação sobre os valores ou formato esperados e o valor atual. Todos os valores são tratados pela interface como texto.  
Cada variável possui edição independente e sua própria ação Salvar. Não existe ação Salvar tudo.  
Salvar permanece indisponível enquanto não houver alteração ou quando o campo estiver vazio. O sistema não admite variável com valor vazio.  
A interface não executa validação semântica específica de S/N, números, datas ou outros formatos descritos. A orientação comunica o domínio esperado e o administrador é responsável pelo conteúdo informado.  
Depois de um salvamento bem-sucedido, o novo valor passa a ser o valor vigente imediatamente. A estratégia técnica de leitura ou cache pertence à implementação do back e não altera esta regra funcional.

### Falha de configuração no consumo

Cada consumidor interpreta o texto conforme a definição da variável que utiliza. Se um valor configurado não puder ser interpretado no momento do uso, a operação não utiliza fallback silencioso nem tenta corrigir automaticamente a configuração.  
A situação é tratada como erro de servidor decorrente de configuração inválida das Variáveis do Sistema. A resposta deve identificar claramente essa natureza de erro para permitir diagnóstico, sem transformar a tela administrativa em um sistema complexo de validação por tipo.
