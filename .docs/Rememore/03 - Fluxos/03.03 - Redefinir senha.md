# 03.03 \- Redefinir senha

## FLUXO

```text
[Fluxo: Entrar no Rememore]
        |
        +-- redefinir senha
                  |
                  -->
[Tela: Redefinir senha | rota: /redefinir-senha | estado: padrao]
 campos: nome de usuario, chave de redefinicao, nova senha
        |
        +-- voltar --> [Fluxo: Entrar no Rememore]
        |
        +-- redefinir senha --> [Validar redefinicao]
                                      |
                                      +-- invalida --> [mesma tela | estado: erro de redefinicao]
                                      |                       |
                                      |                       +-- redefinir senha --> [Validar redefinicao]
                                      |
                                      +-- valida
                                             |
                                             | substitui senha
                                             | invalida chaves anteriores
                                             | invalida todas as sessoes
                                             | emite nova chave do usuario
                                             |
                                             -->
                    [Tela: Redefinir senha / Confirmacao
                     rota: /redefinir-senha/confirmacao
                     estado: confirmacao da chave
                     dado: nova chave de redefinicao]
                                             |
                                             +-- copiar chave
                                                    |
                                                    -->
                                    [mesma tela | feedback temporario de copia]
                                                    |
                                                    +-- entrar
                                                           |
                                                           -->
                                  [Fluxo: Orientar-se pelo ambiente principal]
```

## DETALHES

### Objetivo

Substituir a senha de uma conta por meio de uma chave de redefinição válida, receber uma nova chave do usuário, poder copiá-la e concluir o ingresso direto no ambiente principal depois de confirmar que ela já foi guardada.

### Redefinir senha

Rota: /redefinir-senha  
Condição de acesso: somente sem sessão autenticada.  
Campos: nome de usuário; chave de redefinição; nova senha.  
Estados: padrão; erro de redefinição.  
Ações: Redefinir senha; Voltar.

### Redefinir senha / Confirmação

Rota: /redefinir-senha/confirmacao  
Dados apresentados: nova chave de redefinição do usuário.  
Estado: confirmação da chave, com feedback temporário quando a cópia pelo botão for bem-sucedida.  
Ações: Copiar chave; Entrar, sempre disponível. Entrar exige confirmação explícita de que a chave já foi guardada.

## TRANSIÇÕES

T01  
de: Fluxo: Entrar no Rememore  
ação: Redefinir senha  
condição: usuário sem sessão autenticada  
para: Redefinir senha (/redefinir-senha)\#padrao

T02  
de: Redefinir senha (/redefinir-senha)\#padrao ou \#erro-de-redefinicao  
ação: Voltar  
para: Fluxo: Entrar no Rememore

T03  
de: Redefinir senha (/redefinir-senha)\#padrao ou \#erro-de-redefinicao  
ação: Redefinir senha  
campos de entrada: nome de usuário; chave de redefinição; nova senha  
condição: redefinição inválida por qualquer motivo  
processo: validar conforme 02.06 / Redefinição de senha  
efeito: apresentar mensagem genérica de redefinição inválida, sem revelar o motivo  
para: Redefinir senha (/redefinir-senha)\#erro-de-redefinicao

T04  
de: Redefinir senha (/redefinir-senha)\#padrao ou \#erro-de-redefinicao  
ação: Redefinir senha  
campos de entrada: nome de usuário; chave de redefinição; nova senha  
condição: redefinição válida  
processo: substituir a senha, invalidar as chaves anteriores aplicáveis e todas as sessões existentes e emitir nova chave do usuário conforme 02.00 / Ratificações e 02.06 / Redefinição de senha  
efeito: senha substituída; conta permanece não autenticada; nova chave do usuário emitida  
para: Redefinir senha / Confirmação (/redefinir-senha/confirmacao)\#confirmacao

T05  
de: Redefinir senha / Confirmação (/redefinir-senha/confirmacao)\#confirmacao  
ação: Copiar chave  
efeito: copiar a nova chave e apresentar feedback temporário de cópia, sem condicionar a continuidade  
para: Redefinir senha / Confirmação (/redefinir-senha/confirmacao)\#confirmacao

T06  
de: Redefinir senha / Confirmação (/redefinir-senha/confirmacao)\#confirmacao  
ação: Entrar  
condição: confirmação positiva de que a nova chave já foi guardada  
processo: perguntar se a nova chave já foi guardada; Sim estabelece nova sessão autenticada conforme a política vigente; Não ou cancelamento mantém a confirmação  
efeito: autenticação concluída diretamente após a confirmação da nova chave  
para: Fluxo: Orientar-se pelo ambiente principal
