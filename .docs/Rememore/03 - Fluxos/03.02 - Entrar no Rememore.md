# 03.02 \- Entrar no Rememore

## FLUXO

```text
[Tela: Pagina inicial | rota: /]
        |
        +-- criar conta --> [Fluxo: Criar conta por convite]
        |
        +-- entrar
               |
               -->
[Tela: Entrar | rota: /entrar | estado: padrao]
 campos: nome de usuario, senha
        |
        +-- redefinir senha --> [Fluxo: Redefinir senha]
        |
        +-- entrar --> [Validar credenciais]
                              |
                              +-- invalidas --> [mesma tela | estado: erro de autenticacao]
                              |                       |
                              |                       +-- entrar --> [Validar credenciais]
                              |
                              +-- validas
                                     |
                                     | estabelece nova sessao
                                     | encerra sessoes anteriores
                                     |
                                     -->
                         [Fluxo: Orientar-se pelo ambiente principal]
```

## DETALHES

### Objetivo

Autenticar uma conta existente com nome de usuário e senha e concluir o ingresso no ambiente principal.

### Referências

02.06 \- Conta, Dados e Administração / Login e credenciais inválidas; Sessão; Ambiente principal.  
02.05 \- Modelo de Trabalho e Continuidade / Sessões e dispositivos.

### Página inicial

Rota: /  
Campos e dados deste fluxo: nenhum.  
Estados: padrão.  
Ações: Criar conta; Entrar.

### Entrar

Rota: /entrar  
Campos: nome de usuário; senha.  
Estados: padrão; erro de autenticação.  
Ações: Entrar; Redefinir senha.

## TRANSIÇÕES

T01  
de: Página inicial (/)  
ação: Entrar  
para: Entrar (/entrar)\#padrao

T02  
de: Página inicial (/)  
ação: Criar conta  
para: Fluxo: Criar conta por convite

T03  
de: Entrar (/entrar)\#padrao ou \#erro-de-autenticacao  
ação: Entrar  
campos de entrada: nome de usuário; senha  
condição: credenciais inválidas  
processo: validar conforme 02.06 / Login e credenciais inválidas  
efeito: apresentar mensagem genérica de autenticação inválida  
para: Entrar (/entrar)\#erro-de-autenticacao

T04  
de: Entrar (/entrar)\#padrao ou \#erro-de-autenticacao  
ação: Entrar  
campos de entrada: nome de usuário; senha  
condição: credenciais válidas  
processo: estabelecer a nova sessão e encerrar sessões anteriores conforme 02.06 / Sessão  
efeito: sessão autenticada mais recente estabelecida  
para: Fluxo: Orientar-se pelo ambiente principal

T05  
de: Entrar (/entrar)\#padrao ou \#erro-de-autenticacao  
ação: Redefinir senha  
para: Fluxo: Redefinir senha
