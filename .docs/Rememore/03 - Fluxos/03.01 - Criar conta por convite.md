# 03.01 \- Criar conta por convite

## FLUXO

```text
[Link de convite] -- convite pre-preenchido --+
                                               |
[Tela: Pagina inicial | rota: /]               |
        |                                       |
        +-- criar conta ------------------------+
        |
        +-- entrar --> [Fluxo: Entrar no Rememore]
                                               |
                                               -->
[Tela: Criar conta / Cadastro | rota: /cadastro | estado: padrao]
 campos: convite, nome de usuario, senha
        |
        +-- criar conta --> [Validar cadastro]
                                  |
                                  +-- invalido --> [mesma tela | estado: erro de validacao]
                                  |                     |
                                  |                     +-- criar conta --> [Validar cadastro]
                                  |
                                  +-- valido --> [Tela: Criar conta / Confirmacao
                                                   rota: /cadastro/confirmacao
                                                   estado: confirmacao da chave
                                                   dado: chave de redefinicao]
                                                          |
                                                          +-- copiar chave
                                                                 |
                                                                 -->
                                              [mesma tela | feedback temporario de copia]
                                                                 |
                                                                 +-- entrar
                                                                        |
                                                                        -->
                                                  [Fluxo: Orientar-se pelo ambiente principal]
```

## DETALHES

### Objetivo

Usar um convite válido para criar a conta mínima, receber a chave de redefinição do usuário e concluir o ingresso no Rememore.

### Referências

02.06 \- Conta, Dados e Administração / Estágio fechado e página inicial; Convites; Criação da conta.  
02.02 \- Modelo Conceitual / Pessoa, usuário e conta; Convite; Chave de redefinição do usuário.  
02.07 \- Linguagem e Princípios de Interação / segurança, simplicidade e contexto.  
02.00 \- Mapa da Consolidação / Ratificações / 02.06 \- Conta, Dados e Administração / Criação da conta.

### Página inicial

Rota: /  
Campos e dados deste fluxo: nenhum.  
Estados: padrão.  
Ações: Criar conta; Entrar.

### Criar conta / Cadastro

Rota: /cadastro  
Campos: convite; nome de usuário; senha.  
Estados: padrão; erro de validação.  
Ações: Criar conta.

### Criar conta / Confirmação

Rota: /cadastro/confirmacao  
Dados apresentados: chave de redefinição do usuário.  
Estado: confirmação da chave, com feedback temporário quando a cópia pelo botão for bem-sucedida.  
Ações: Copiar chave; Entrar, sempre disponível. Entrar exige confirmação explícita de que a chave já foi guardada.

## TRANSIÇÕES

T01  
de: Página inicial (/)  
ação: Criar conta  
para: Criar conta / Cadastro (/cadastro)\#padrao

T02  
de: Link de convite  
evento: Abrir o link  
dados de entrada: convite  
efeito: preencher o campo convite  
para: Criar conta / Cadastro (/cadastro)\#padrao

T03  
de: Página inicial (/)  
ação: Entrar  
para: Fluxo: Entrar no Rememore

T04  
de: Criar conta / Cadastro (/cadastro)\#padrao ou \#erro-de-validacao  
ação: Criar conta  
campos de entrada: convite; nome de usuário; senha  
condição: cadastro inválido  
processo: validar conforme 02.06 / Convites; Criação da conta  
efeito: apresentar o erro específico aplicável  
para: Criar conta / Cadastro (/cadastro)\#erro-de-validacao

T05  
de: Criar conta / Cadastro (/cadastro)\#padrao ou \#erro-de-validacao  
ação: Criar conta  
campos de entrada: convite; nome de usuário; senha  
condição: cadastro válido  
processo: criar a conta e consumir o convite conforme 02.06 / Convites; Criação da conta; emitir a chave de redefinição do usuário, sem estabelecer sessão autenticada  
efeito: conta criada, convite utilizado e chave de redefinição emitida; usuário permanece sem sessão autenticada até a confirmação  
para: Criar conta / Confirmação (/cadastro/confirmacao)\#confirmacao

T06  
de: Criar conta / Confirmação (/cadastro/confirmacao)\#confirmacao  
ação: Copiar chave  
efeito: copiar a chave e apresentar feedback temporário de cópia, sem condicionar a continuidade  
para: Criar conta / Confirmação (/cadastro/confirmacao)\#confirmacao

T07  
de: Criar conta / Confirmação (/cadastro/confirmacao)\#confirmacao  
ação: Entrar  
processo: perguntar se a chave já foi guardada; Sim estabelece a sessão autenticada conforme a política vigente e as ratificações aplicáveis; Não ou cancelamento mantém a confirmação  
para: Fluxo: Orientar-se pelo ambiente principal
