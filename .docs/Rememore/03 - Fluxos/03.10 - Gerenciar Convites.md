# 03.10 \- Gerenciar Convites

## FLUXO

```text
[Área administrativa]
        |
        +-- convites
               |
               -->
[Tela: Gerenciar Convites | rota: /admin/convites]

 estados: disponível | utilizado | expirado | revogado
        |
        +-- gerar convite
        |      |
        |      --> [Novo convite gerado]
        |              dados: código, geração, expiração
        |              |
        |              +-- copiar código
        |              |
        |              +-- concluir --> [Gerenciar Convites]
        |
        +-- convite disponível
        |      |
        |      +-- copiar código
        |      |
        |      +-- revogar
        |             |
        |             --> [Confirmar revogação]
        |                    |
        |                    +-- cancelar --> [Gerenciar Convites]
        |                    |
        |                    +-- confirmar --> convite = revogado
        |
        +-- convite utilizado / expirado / revogado
        |      |
        |      +-- remover da listagem
        |             |
        |             --> [Confirmar remoção]

        |                    |

        |
        +-- voltar --> [Área administrativa]
```

## DETALHES

### Objetivo

Permitir ao administrador acompanhar convites operacionais, gerar novos códigos e executar as ações permitidas conforme o estado de cada convite.

### Referências

02.06 \- Conta, Dados e Administração / Convites; Administração do serviço; Limites de privacidade do administrador.  
02.02 \- Modelo Conceitual / Convite.  
02.00 \- Mapa da Consolidação / Ratificações / Gerenciar Convites.

### Estrutura do fluxo

Gerenciar Convites é uma jornada administrativa única. A listagem é o ponto central e concentra geração, consulta do estado, cópia do código quando aplicável, revogação e remoção operacional.

### Listagem

Rota funcional: /admin/convites.  
Cada convite apresenta código, data de geração, data de expiração e estado. A listagem é ordenada do convite mais recentemente gerado para o mais antigo e não utiliza busca, filtros ou paginação no escopo vigente.  
Os estados possíveis são disponível, utilizado, expirado e revogado.  
O convite não é previamente associado a uma pessoa.

### Geração e código

Gerar convite cria um novo convite disponível com validade de sete dias.  
O código gerado pode ser copiado imediatamente e permanece visível e copiável enquanto o convite disponível permanecer na listagem operacional.  
A entrega do código ocorre fora do Rememore; o sistema não incorpora gestão de destinatários, e-mail ou mensagens internas.

### Revogação

Somente convites disponíveis podem ser revogados.  
Revogar é irreversível e torna o convite definitivamente inutilizável.  
A ação exige confirmação explícita antes de alterar o estado para revogado.

### Remoção da listagem

Convites utilizados, expirados ou revogados podem ser removidos da listagem operacional.  
A remoção exige confirmação simples para evitar ação acidental.  
Remover da listagem não torna o convite reutilizável e não elimina a referência histórica necessária quando o convite tiver originado uma conta.  
Convite utilizado permanece não reutilizável mesmo se a conta correspondente for posteriormente excluída.

ação: Copiar código

ação: Concluir  
para: Gerenciar Convites

para: Gerenciar Convites

T06  
de: Gerenciar Convites  
ação: Revogar  
condição: convite disponível  
para: Confirmar revogação

T07  
de: Confirmar revogação  
ação: Cancelar  
para: Gerenciar Convites

T08

para: Gerenciar Convites

ação: Cancelar  
para: Gerenciar Convites

T11  
de: Confirmar remoção

para: Gerenciar Convites

ação: Voltar  
para: Área administrativa
