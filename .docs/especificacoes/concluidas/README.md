# Especificações encerradas — Stack .NET

O programador move para este diretório os arquivos operacionais das unidades cujo encerramento foi solicitado pelo operador e cujo Parecer final já foi registrado. Preservar corpo aprovado, checkpoints, Parecer e eventuais adendos de publicação. Após aceite e encerramento explícito, o **Codex** executa commit e push na `develop`, registra os hashes conhecidos e a confirmação real em Parecer/adendo e comunica ao operador; sem publicação em `main` implícita. Este arquivo mantém o diretório versionado, mas **não autoriza leitura indiscriminada** de unidades encerradas no início de outras sessões.
