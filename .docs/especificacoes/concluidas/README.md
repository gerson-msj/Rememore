# Especificações encerradas — Stack .NET

O programador move para este diretório os arquivos operacionais das unidades cujo encerramento foi solicitado pelo operador e cujo Parecer final já foi registrado. Preservar corpo aprovado, checkpoints e Parecer. Este arquivo mantém o diretório versionado, mas **não autoriza leitura indiscriminada** de unidades encerradas no início de outras sessões.
