# Instruções de trabalho — Stack3

## Projeto

Rememore é um projeto baseado em Bun e React para gerenciar memórias dos usuários. Está em desenvolvimento assistido por IA, na fase 1, e esta é a terceira Stack em teste; as duas primeiras falharam. Todas as definições serão dadas pelo operador. Um dos objetivos é apoiar o aprendizado do operador, com a possibilidade de o Rememore se tornar um produto futuramente.

Ao operar neste diretório (`Stack3`), não leia orientações localizadas em diretórios acima dele. Use somente as instruções e os documentos disponíveis dentro de `Stack3`, além das instruções fornecidas diretamente pelo operador na conversa.

Leia este `AGENTS.md` novamente a cada compactação da sessão. Leia também `.docs/memoria-tecnica.md` no início de cada nova sessão e novamente após cada compactação. Se não conseguir identificar que houve uma compactação, o operador avisará.
